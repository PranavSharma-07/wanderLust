# WanderLust 🏡

A full-stack Airbnb-inspired web application built while learning backend development with Node.js, Express.js, MongoDB, and modern web development practices.

## Features

- User Authentication (Signup, Login, Logout)
- Authorization (Listing & Review Ownership)
- Create Listings
- View Listing Details
- Edit Listings
- Delete Listings
- Add Reviews
- Delete Reviews
- MongoDB Relationships (Listings & Reviews)
- Joi Validation
- Custom Error Handling
- Express Middleware
- Express Router
- RESTful Routes
- Sessions & Cookies
- Flash Messages
- Image Upload (Cloudinary)
- Image Editing
- Cloud Image Storage

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap 5
- Joi
- Passport.js
- Cloudinary
- Multer
- Multer-Storage-Cloudinary
- passport-local
- passport-local-mongoose
- express-session
- connect-flash
- method-override
