# WanderLust 🏡

A full-stack Airbnb-inspired web application built while learning the MERN Stack.

## Features

- Create Listings
- View Listing Details
- Edit Listings
- Delete Listings
- Add Reviews
- Delete Reviews
- Joi Validation
- Custom Error Handling
- Express Middleware
- Express Router
- Sessions & Cookies
- Flash Messages (Success/Error)
- RESTful Routes
- MongoDB Relationships (Listings & Reviews)

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap 5
- Joi
- express-session
- connect-flash
- method-override
