# WanderLust 🏡

A full-stack Airbnb-inspired web application built while learning the MERN Stack.

## Features

- Create Listings
- Edit Listings
- Delete Listings
- Add Reviews
- Delete Reviews
- Joi Validation
- Custom Error Handling
- Express Middleware

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- Joi

## Current Status

🚧 Authentication and Authorization are currently in progress.
